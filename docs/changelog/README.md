# Change log

One file per change made after the FYP-1 mid report (2026-10-22). The mid report is frozen; these entries are the record from which the final report will be written later.

**File name:** `YYYY-MM-DD-NN-short-slug.md`, where `NN` numbers the changes of that day in order.

**Entry template:**

```markdown
# <Title>

- **Date:** YYYY-MM-DD
- **Type:** code | test | decision | docs | hardware | ops
- **Module:** M1 CA tool | M2 firmware | M3 provisioning app | M4 ML | M5 gateway | M6 relay app | M7 cloud | M8 dashboard | project
- **Commits:** <hashes, or "pending">

## What changed
<what is different now>

## Why
<the reason or the problem it solves>

## Evidence
<tests, results, logs, or "none">
```

Decisions are also updated in `docs/decisions/`; the entry here records when and why they changed.
